# 약속 여행

유치원생이 걷는 친구와 결승점까지 남은 거리로 시간을 이해하는 한국어 비주얼 타이머입니다.

**배포 주소: https://neegiman.github.io/timer/**

**저장소: https://github.com/neegiman/timer**

## 실행과 정적 빌드

Node.js 22와 npm을 사용합니다.

```sh
npm ci
npm run dev
```

개발 주소는 `http://localhost:3000/timer/`입니다. 앱은 `/timer`에 설치합니다.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview -- --port 17832
```

빌드는 `out/`를 생성합니다. `next.config.ts`는 `output: 'export'`, `basePath: '/timer'`, `trailingSlash: true`, `images.unoptimized: true`를 설정합니다. 빌드 후 Next.js 서버, API, 데이터베이스, 인증 서버가 필요하지 않습니다. `preview`는 로컬 검사에만 사용하는 파일 서버입니다.

`scripts/verify-export.mjs`가 생성된 HTML/CSS/JS의 경로와 `_next` 파일, 이미지, 11개 MP3를 확인합니다. 자산은 모두 `src/lib/assetPath.ts`의 `assetPath()`를 통해 `/timer` 접두어를 사용합니다.

```ts
assetPath('/sounds/finish.mp3'); // /timer/sounds/finish.mp3
assetPath('/images/meadow.svg'); // /timer/images/meadow.svg
assetPath('/characters/rabbit.webp'); // /timer/characters/rabbit.webp
```

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**는 **GitHub Actions**로 설정합니다. `main`에 푸시하거나 **Deploy Next.js to GitHub Pages** 워크플로를 직접 실행합니다.

`.github/workflows/deploy.yml`은 Node 22, `npm ci`, 타입 검사, 린트, 단위 검사, 정적 빌드, `out/` 확인, Pages 업로드와 배포를 실행합니다. `out/`, `.next/`, `node_modules/`는 커밋하지 않습니다. 도메인 루트 `https://neegiman.github.io/`로 배포 설정을 바꾸지 마세요.

```sh
npm run verify:live
```

게시된 `/timer/`의 HTML, Next.js 자산, 이미지, 11개 MP3 및 새로고침 응답을 확인합니다. 게시 완료 여부는 GitHub Actions의 배포 성공과 실제 URL의 응답으로 확인합니다.

## 사용 방법

1. 씻기·잠자기·밥 먹기·정리·외출 준비·영상 종료 또는 직접 약속을 고릅니다.
2. 5·10·15·20·30분 또는 1~120분을 정합니다.
3. 토끼·공주·강아지·고양이·병아리·자동차·기차·로켓을 고르고 **출발!**을 누릅니다.
4. 친구가 도착하면 약속한 일을 하고 **⭐ 약속 지켰어요**로 별 하나를 받습니다.

한 화면에 한 가지를 고르는 준비 흐름, 큰 아이콘과 부드러운 색상을 유지합니다. 동물 네 종과 공주는 ImageGen 원화의 부위별 이미지, 자동차·기차·로켓은 기존 SVG를 사용합니다. 긴 머리 공주는 두 발을 교대하고 어깨·팔꿈치로 팔을 반대로 흔드는 별도의 보행 프로필을 사용합니다. [공주 원화·생성 프롬프트](docs/character-design/princess-v2/README.md), [현재 관절 중심선·굵기·몸통 연결과 보행 캡처](docs/character-design/princess-rig-v4/README.md)를 참고하세요. 숫자와 소리는 부모 메뉴에서 끌 수 있습니다. 일시정지·계속·처음부터·종료·전체화면도 부모 메뉴에 있습니다. 재시작과 종료에는 확인창이 있습니다.

별은 약속을 지킨 여행마다 한 번만 받습니다. 별을 빼거나 아이를 비교하지 않습니다. 상단에는 전체 누적 별을 표시하고, 달력에서 날짜별로 확인합니다. 날짜가 바뀌어도 모은 별은 보존되며, 완료된 여행에서 보상을 다시 받을 수는 없습니다.

## 위치와 시간에 맞는 낮·밤 배경

**부모 메뉴 → 하늘과 배경 → 자동 → 현재 위치로 맞추기**를 누르고 브라우저의 위치 사용을 허용하면, 현재 위도·경도와 실제 시각으로 낮과 밤을 계산합니다. 낮에는 해와 밝은 초원, 밤에는 달·별과 푸른 초원을 보여줍니다. 캐릭터와 길은 밤에도 잘 보이게 유지합니다. 하늘과 풍경 색은 부드럽게 전환하며 보행·배경 스크롤·타이머를 다시 시작하지 않습니다.

`src/lib/dayNight.ts`는 [NOAA의 태양 위치 계산식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)을 UTC와 좌표에 적용합니다. 태양 고도 -0.833°를 낮·밤 경계로 사용하여 계절, 남반구, 백야·극야도 반영합니다. 기기 시간대가 실제 위치와 달라도 좌표가 있으면 해당 위치의 햇빛을 기준으로 합니다. 외부 일출 API, 날씨 API, 시간대 조회나 서버는 필요하지 않습니다.

위치를 선택하지 않거나 허용하지 않은 경우, 확인이 실패한 경우에는 **기기 현지 시간 06:00~18:00를 낮**, 그 외를 밤으로 사용합니다. 페이지를 열기만 해서는 위치 허용창을 띄우지 않습니다. 이미 위치 사용을 선택했고 권한이 허용된 브라우저는 새로고침 후 다시 확인합니다. 권한 상태 조회를 지원하지 않는 브라우저에서는 필요할 때 위치 버튼을 다시 눌러 주세요. **기기 시간만 사용**으로 위치 확인을 끌 수 있습니다.

**낮 / 밤** 버튼으로 원하는 배경을 고정할 수도 있습니다. 배경 선택과 위치 사용 여부만 저장하고, 위도·경도는 현재 탭의 메모리에서만 사용합니다. `watchPosition`은 정확한 GPS가 필요 없는 저전력 설정으로 위치 변경을 반영합니다. 매분과 백그라운드 복귀 시 현재 시각을 적용하며, 타이머를 일시정지해도 낮·밤은 실제 시각을 따릅니다. 모션 감소 환경에서는 배경 전환 효과도 줄입니다.

주요 파일은 `src/hooks/useDayNight.ts`, `src/components/SceneSettings.tsx`, `JourneyPath.tsx`, `ScrollingScenery.tsx`, `globals.css`, `src/lib/paintedScenery.json`, `public/images/scenery-v1/`입니다. 기존 캐릭터와 UI를 유지하며 새 라이브러리를 추가하지 않았습니다.

## 대한민국 사계절과 작은 풍경 이벤트

계절 자동 모드에서는 기기의 시간대나 위치와 관계없이 **한국 시간(KST)의 달력**에 맞춰 3개월마다 바뀝니다. **부모 메뉴 → 하늘과 배경 → 계절 선택**에서 봄·여름·가을·겨울을 고정하고, 아래 **낮 · 밤 선택**과 조합해 배경 8종을 직접 테스트할 수 있습니다. 선택은 새로고침 후에도 유지하며 **계절 자동**을 누르면 한국 달력 기준으로 돌아갑니다. 낮·밤의 **자동**은 기존 위치/기기 시간 기준으로 돌아갑니다. 타이머를 멈춰도 자동 모드의 실제 날짜·시간에 따른 배경 전환은 적용합니다.

| 계절 | 기간 | 풍경과 방문 이벤트 |
| --- | --- | --- |
| 봄 | 3~5월 | 분홍 꽃나무·꽃잎, 제비와 나비 |
| 여름 | 6~8월 | 짙은 초록 나무·풀숲, 백로와 잠자리 |
| 가을 | 9~11월 | 주황 단풍·낙엽, 기러기 무리와 흩날리는 잎 |
| 겨울 | 12~2월 | 눈 덮인 나무·길·따뜻한 창빛, 박새와 눈송이 |

낮에는 계절별 새가 날개를 움직이며 지나갑니다. 밤에는 모든 계절에서 48초 주기의 10초 지점부터 2.6초 동안 별똥별이 대각선으로 지나가고 꼬리가 사라집니다. 봄·여름 밤의 반딧불 등 다른 방문 이벤트는 30초 지점에 9초 동안 나타납니다. 낮의 새와 계절 방문 이벤트는 7~9초씩 두 번 등장하며 사이에 조용한 구간을 둡니다. 입자는 최대 6개로 제한하며 반복 경계에서는 투명해집니다. 모두 기존 `requestAnimationFrame`과 **실제 경과 시간**을 사용해 일시정지·재개·새로고침에서도 같은 위치를 복원합니다. 완료 후에는 움직임을 멈추며, 모션 감소 설정에서는 입자와 방문 이벤트를 숨깁니다. 고정된 오른쪽 도착점은 풍경과 함께 움직이지 않습니다. 소리 켜기 버튼은 여행 화면 아래에 24px 간격을 둡니다.

`src/lib/seasons.ts`, `sceneryEvents.ts`, `SeasonalAtmosphere.tsx`에 계절·이벤트를 분리했습니다. 배경은 원화풍 낮·밤 풍경과 투명 나무 레이어로 교체했습니다. 모든 원화는 저장소의 정적 파일이며 외부 이미지 서비스, 추가 라이브러리, 날씨 서버가 필요하지 않습니다.

[현재 사계절 원화 배경·낮밤 화면 8종·프롬프트·제작 기록](docs/background-design/painted-v1/README.md)을 참고하세요. `npm run scenery`로 원본을 다시 분리·변환합니다. 먼 풍경/나무/길은 0.14/0.55/1배의 속도로 흐르고, 화면 높이에 맞춘 타일 크기와 반사 연결로 반복 경계를 감춥니다. 길은 기존 발걸음 시계와 함께 움직이며 결승점은 고정합니다. 빛과 계절 이벤트는 일시정지·완료 때 같이 멈춥니다.

2026-10-09 검증: 타입 검사·린트·정적 내보내기와 단위 검사 61개 통과. 사계절·문구·낮밤·기존 애니메이션·전체화면의 Chromium/모바일 WebKit 시나리오 37개 통과. 이 환경에서 지원하지 않는 WebKit 네이티브 전체화면 1개는 건너뛰었으며, 대체 큰 화면 모드는 두 브라우저에서 확인했습니다.

## 고정 보행과 횡스크롤

메인 캐릭터는 여행 대부분을 장면 너비의 **42%**에서 걷습니다. 도착점이 보이는 **마지막 10% 구간 전체**에서 고정 결승점까지 거리를 계속 줄이고, 정확히 0초에 선에 도착합니다. 짧은 여행의 넓은 화면에서는 같은 보행 속도로 거리를 소화하도록 접근을 조금 앞당깁니다. 마지막 몇 초까지 같은 간격으로 머물다가 갑자기 접근하지 않습니다. 0초 이후 선을 완전히 넘어 감속한 뒤 축하합니다. 위쪽의 작은 캐릭터는 실제 경과 시간에 비례해 집에서 깃발까지 이동합니다. 메인 위치는 진행률을 직접 곱하지 않고 보행 속도와 결승점 사이의 거리로 계산합니다.

`Timestamp Timer → AnimationController → Shared Locomotion Clock → SVG Joints / Scenery / Destination` 구조입니다.

- `src/lib/animation.ts`: 메시지 단계와 `READY / WALK / CROSS_FINISH / BRAKE / SETTLE / JUMP / LAND / CELEBRATE` 상태를 계산합니다. 50%와 90%에서 걷기 주기를 재시작하거나 달리기로 바꾸지 않습니다.
- `src/lib/arrivalMotion.ts`: 화면 크기별 고정 결승점과 통과 후 정지 위치를 계산합니다. 접근 때는 캐릭터 이동과 배경 스크롤에 같은 보행 거리를 나누고, 통과 때는 실제 이동 거리에 보행 주기를 맞춰 발 미끄러짐을 줄입니다.
- `src/lib/journey.ts`: 부드러운 속도 전환, 보행 시계, 지면 거리, 반복 타일 오프셋, 마지막 10% 결승점의 등장 투명도를 계산합니다. 프레임 수를 시간으로 사용하지 않습니다.
- `src/lib/animalMotion.ts`, `animalActionPose.ts`: 동물별 네 발 또는 두 발의 순서, 두 관절 IK, 발목 보정, 몸의 작은 움직임, 귀·꼬리·머리, 종료 시 안정화·점프·착지·축하 자세를 계산합니다. 토끼는 두 뒷발을 함께 밀고, 강아지·고양이는 네 발로 걷고, 병아리는 두 발을 교대합니다. `characterPose.ts`는 기존 차량의 관절·바퀴 계산을 유지합니다.
- `src/lib/motionProfiles.ts`: 친구별 보행 주기와 발바닥 기준 높이를 정의합니다. 자동차·기차는 바퀴 둘레에 맞춰 지면과 함께 회전합니다.
- `src/hooks/useJourneyRenderer.ts`: `requestAnimationFrame`에서 DOM의 `translate3d`, 원화 부위의 SVG 관절, Web Animation의 `currentTime`만 갱신합니다. React state는 매 프레임 갱신하지 않습니다. ResizeObserver로 크기를 캐시하고 소수점 캐릭터 폭을 사용해 동물별 보폭과 지면 속도를 맞춥니다. 동물은 시안 화면과 같은 보행 함수를 사용합니다.
- `src/components/timer/ScrollingScenery.tsx`: 원화풍 풍경·투명 나무·길을 분리한 세 개의 반복 WebP 레이어입니다. 풍경 0.14 / 나무 0.55 / 지면 1.00의 상대 속도로 움직이며, 반사 연결 타일의 양 끝이 이어집니다. `SeasonalBird.tsx`는 계절별 새와 날개 관절을 표현합니다. 화면 전체를 흔들지 않습니다.
- `JourneyProgress.tsx`: 출발·도착 아이콘, 지나온 길, 실제 시간에 맞춰 이동하는 작은 친구입니다.
- `JourneyMessage.tsx`, `src/lib/journeyNotice.ts`: 실제 경과 시간에 따라 안내 문구를 잠시 표시하고 숨깁니다. 긴 문구의 공간을 미리 확보해 사라질 때에도 장면 높이가 갑자기 바뀌지 않습니다.
- `JourneyPath.tsx`: 전신 친구, 반복 배경과 **별도 단일 결승점 레이어**를 배치합니다. 도착점은 90%부터 부드럽게 나타나며 지면 높이 78%에 고정됩니다. 깃발 천·깃대·도착선·도착 그림과 문구 모두 움직이지 않습니다. 화면 오른쪽에 캐릭터 전체가 통과할 공간을 확보하며 배경 스크롤이나 진행률에 따라 움직이지 않습니다. 위쪽 경로의 작은 친구는 정확히 100%에 도착점을 표시합니다.
- `VisualTimer.tsx`, `src/app/globals.css`: 큰 상단 문구, 보조 숫자 시간, 진행 경로, 장면과 약속을 배치합니다. 320px부터 세로·가로·전체화면을 지원하며, 기존 디자인 토큰과 부모 메뉴를 유지합니다.

전체화면에서도 도착·완료·별 보상 시 장면 높이를 줄이지 않아 결승선과 지면이 같은 자리에 남습니다. 소리 재활성화 버튼은 장면 아래에 표시해 오디오가 중단되어도 여행 화면을 밀거나 축소하지 않습니다.

발이 지면을 지지하는 동안 발의 뒤쪽 이동 속도는 배경 스크롤과 캐릭터 전진 속도의 합과 같습니다. 시작·접근·결승선 통과에는 부드러운 속도 전환을 적용합니다. 50%·90%와 마지막 10초·3초에도 보행 속도가 갑자기 높아지지 않습니다.

| 경과 진행률 | 안내 예시: 씻기 · 활동 시작 |
| --- | --- |
| 0~49% | 조금 뒤에 씻기를 시작해요. 🛁 |
| 50~89% | 씻기 전 기다림이 절반 지났어요! 🌟 |
| 90~99% | 목욕할 시간이 가까워졌어요! 🛁 |
| 100% | 목욕하러 가요. 🛁 |

문구는 계속 띄워두지 않습니다. 1~15분 여행은 **30초**, 16~30분은 **60초**, 31~120분은 **90초** 간격으로 약 6초씩 표시합니다. 출발·50%·90% 안내는 8초, 마지막 10초 구간에는 도착 직전 안내를 보여주며 완료 안내는 유지합니다. 중요한 지점 근처에는 반복 안내를 생략해 연속으로 깜빡이지 않습니다. 일시정지는 표시 시간도 멈추고, 백그라운드에서 놓친 안내는 복귀 시 몰아서 재생하지 않습니다.

문구가 없는 동안에는 같은 자리에 선택한 약속 그림과 은은하게 반짝이는 네 개의 별을 표시합니다. 문구와 그림을 부드럽게 교대해 빈 공간을 채우면서 숫자·진행 경로·캐릭터와 배경의 위치를 유지합니다. 기존 원화 아이콘을 재사용하고 효과는 CSS의 opacity·transform만 사용합니다. 일시정지·탭 비활성화 때 효과를 멈추며, 동작 줄이기 설정에서는 정적인 그림으로 표시합니다. 장식은 화면 읽기 프로그램에 반복 안내하지 않습니다.

50%에서는 별이 살짝 반짝이며 캐릭터는 계속 걷습니다. 0초에 결승선에 도달하고 지면·배경 스크롤을 멈춥니다. `CROSS_FINISH(1600ms) → BRAKE(400ms) → SETTLE(350ms) → JUMP(600ms) → LAND(400ms) → CELEBRATE(1400ms)`를 실행해 선을 완전히 넘은 뒤 축하합니다. 4.75초 뒤 별 보상 버튼을 보여주고 도착 화면을 유지합니다. 완료 효과음은 CELEBRATE에서 한 번 재생합니다.

종료 순서는 저장된 도착 시각으로 복원합니다. 중첩 timeout이나 비동기 delay 체인을 사용하지 않습니다. 새로고침·백그라운드 복귀 시 시각으로 보정하고, 종료·재시작은 이전 프레임과 오디오를 취소합니다.

일시정지하면 타이머, 관절, 몸동작, 배경, 결승점과 작은 진행 캐릭터를 모두 유지합니다. 재개 시 새 종료 시각과 UI 시계를 같은 순간에 갱신해 메시지 임계값을 잠깐 거슬러 올라가지 않습니다. 일시정지 후 새로고침도 같은 자세와 스크롤을 복원합니다.

`prefers-reduced-motion`에서는 반복 관절·바운스·배경 스크롤·큰 축하 동작을 제거하고 별 두 개만 표시합니다. 작은 진행 캐릭터, 결승점 접근과 실제 타이머 시각은 유지합니다.

## 저장과 모바일 소리

`localStorage` 키는 `promise-journey:v1:` 접두어를 사용합니다. 캐릭터, 시간, 약속, 소리, 숫자 표시, 오늘의 별, 진행 중인 여행, 재생한 소리의 기록을 저장합니다. `backgroundMode`에는 자동·낮·밤 선택을, `useLocationBackground`에는 위치 사용 여부를 저장합니다. 좌표는 저장하지 않습니다. 잘못된 데이터는 기본값으로 대체하며 저장소가 제한되면 현재 탭의 메모리로 동작합니다.

실제 종료 시각을 저장합니다. `visibilitychange`와 `pageshow`에서 현재 시각을 확인하므로 탭 전환·화면 잠금·Safari 정지 때문에 시간이 연장되지 않습니다. 만료 후 돌아오면 도착 연출을 시작합니다.

**화면 켜짐 유지**는 기본으로 켜져 있습니다. 여행 진행·도착 연출 중에는 [Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)로 자동 잠금을 막도록 요청합니다. 일시정지·완료·종료·설정 OFF·페이지 이탈 시 해제하며, 복귀·재개 시 다시 요청합니다. `keepScreenAwake`에 부모의 선택을 저장합니다. 부모 메뉴에서 실제 활성 상태와 지원 여부를 확인하고, 거절·시스템 해제 후 다시 시도할 수 있습니다. 진행 중 새로고침에서도 요청을 복원하며 타이머 종료 시각은 바꾸지 않습니다.

화면 켜짐 유지는 HTTPS와 지원 브라우저가 필요합니다. 저전력 모드·배터리·브라우저 정책에 따라 요청이 거절되거나 해제될 수 있으며 직접 누른 잠금 버튼이나 다른 앱에서의 화면 잠금을 막지 않습니다. 지원하지 않거나 거절돼도 타이머·소리·별 보상은 계속 사용할 수 있습니다. `screenWakeLock.ts`는 중복 요청과 뒤늦게 완료된 요청을 정리하고, 시스템 해제에 무한 재시도하지 않습니다. `useScreenWakeLock.ts`는 여행·페이지 수명 주기에 연결합니다.

**출발!** 버튼의 명시적 입력에서 Web Audio 컨텍스트를 활성화하고 MP3를 디코딩합니다. 시작·절반·결승점 인지·도착에는 부드러운 차임을 한 번씩 사용하며 걷는 동안 소리를 반복하지 않습니다. `finish.mp3`와 별 버튼의 `success.mp3`는 서로 다른 효과음입니다. 세션별 재생 기록으로 새로고침 후 완료음을 다시 울리지 않습니다.

`public/sounds/`의 11개 MP3는 직접 합성한 자산이며 `npm run sounds`로 다시 만들 수 있습니다. 현재 흐름에서는 시작·절반·결승점 인지·도착·별 보상 효과음을 사용합니다. 원격 폰트나 이미지에 의존하지 않습니다.

실제 iPhone은 잠금·무음·브라우저 정책에 따라 백그라운드 소리를 막을 수 있습니다. 종료 시각은 유지하며 복귀 후 재생에 다시 탭이 필요하면 **소리 켜기**를 표시합니다. 실행 중 새로고침으로 오디오 컨텍스트가 사라지는 경우도 같은 안내를 제공합니다.

기본 친구는 `type: 'illustration'`입니다. 동물과 공주는 ImageGen의 투명 원화 아틀라스를 SVG 관절에 연결하고, 왕자·자동차·기차·로켓은 오리지널 픽셀 SVG 스프라이트로 렌더링합니다. `type: 'image'`, `src: '/characters/파일명.webp'`에는 `/timer` 접두어가 적용됩니다. 이모지 대체 표시도 지원합니다. [원화 애니메이션 제작 기록](docs/character-design/raster-v1/README.md)에 원본·생성 프롬프트·정적 자산·검증 내용을 보존합니다. 브라우저에 새 애니메이션 라이브러리는 추가하지 않았습니다. Sharp는 빌드 전 이미지 형식 변환과 검사에만 사용하는 개발 의존성입니다.

## 실제 동물 체형과 보행 비교 시안

[동물 움직임 미리보기](https://neegiman.github.io/timer/animal-preview/)에서 토끼·강아지·고양이·병아리의 원화 애니메이션과 보행 구조를 비교합니다. 상단은 현재 선택할 수 있는 ImageGen 동물 원화이고, 하단은 털 질감이 있는 원화를 움직입니다. **보행 구조 보기 / 원화로 보기**로 전환하며 같은 시계를 유지합니다. 실제 동물 관찰 자료를 참고한 근사 모델이며 실측 모션 캡처는 아닙니다.

토끼는 두 뒷발로 밀고 작게 도약하며, 강아지·고양이는 네 발, 병아리는 두 발로 걷습니다. 발의 접지 속도와 지면 이동을 맞추고 귀·꼬리·머리는 별도 관절로 움직입니다. **실제 타이머에도 원화와 같은 보행을 적용했습니다.** 비교 화면은 재생·정지·0.5배속·초기화·모션 감소를 지원하며 저장된 여행은 변경하지 않습니다.

주요 파일은 `PaintedAnimalArtwork.tsx`, `CharacterArtwork.tsx`, `animalAtlases.json`, `animalMotion.ts`, `animalActionPose.ts`, `useJourneyRenderer.ts`입니다. 현재 동물 네 종류의 투명 원본은 `docs/character-design/raster-v1/atlases/`, 실제 브라우저 자산은 `public/characters/raster-v1/`에 있습니다. `npm run characters`로 원본을 자르거나 보정하지 않고 부위 좌표와 무손실 WebP를 재생성합니다. 모든 이미지에 `assetPath()`를 적용합니다.

## 전체화면

**부모 메뉴 → 전체화면**으로 진입하고 **전체화면 끝내기**로 돌아옵니다. 브라우저 Esc나 자체 종료에도 메뉴 상태가 갱신됩니다. 전체 페이지를 대상으로 하므로 부모 메뉴와 확인창도 사용할 수 있습니다.

지원하지 않거나 요청이 거절된 브라우저는 페이지 안에서 확장하는 **큰 화면 보기**를 사용합니다. 이 모드는 주소창을 숨기지 않습니다. Esc는 열린 부모 메뉴부터 닫고, 메뉴가 없으면 큰 화면을 끝냅니다. 새로고침은 기본 화면으로 돌아갑니다. 전환·회전 시 타이머 시각과 별은 유지됩니다.

가로 전체화면은 왼쪽에 장면, 오른쪽에 안내·진행 경로·약속을 배치합니다. 장면 높이는 안정적인 `svh`를 기준으로 하여 모바일 주소창이 열리고 닫힐 때 지면과 도착선이 위아래로 따라 움직이지 않습니다. 완료·보상·소리 재활성화 안내가 나타나도 장면 높이를 유지합니다.

- [토끼 귀·머리 연결 교정](docs/character-design/rabbit-ears-v5/README.md): 귀의 실제 뿌리를 머리 안쪽에 고정하고, 걷기·점프·착지·축하·모션 감소에서 두 귀 각각의 머리 겹침을 실제 픽셀로 검사합니다.

Windows WebKit에는 `AudioContext`가 없어 실제 디코딩·출력 횟수 검사는 Chromium에서 실행합니다. WebKit은 모바일 화면·보행·메시지·제어·복원을 검사합니다. 네이티브 전체화면을 지원하지 않는 모바일 WebKit에서는 해당 검사 하나를 건너뛰고 큰 화면 보기 검사를 실행합니다.

실제 iPhone 하드웨어의 스피커·잠금·복귀 소리는 별도 확인이 필요합니다. Safari에서 씻기 → 10분 → 토끼 → 출발!을 누른 뒤 소리, 일시정지·계속, 잠금·복귀, 도착 소리 한 번, 별 저장과 게시 URL 새로고침을 확인하세요.

2026-10-09 검증: 타입 검사·린트·정적 빌드와 자산 검사 통과, 단위 검사 23개 통과. 전체 시나리오와 수정 대상 재검사에서 브라우저 검사 53개 통과 및 미지원 모바일 네이티브 전체화면 1개 건너뛰기. 낮·밤 모두 휴대폰 세로·가로 화면의 실제 렌더링을 확인했습니다.

동물 시안 추가 후 재검증: 타입 검사·lint·정적 빌드·자산 검사 통과, 단위 검사 28개 통과. 동물 시안과 기존 타이머 도착·보상·일시정지 흐름을 Chromium·모바일 WebKit에서 다시 검사하여 8개 통과. 실제 iPhone 하드웨어 검증을 대체하지는 않습니다.

## 강아지·고양이 관절 보행 적용

곰을 선택 목록·동물 미리보기·런타임 자산에서 제거했습니다. 기존 곰 여행은 시간과 약속을 유지하면서 토끼로 복원합니다. 강아지·고양이에는 토끼와 같은 원화 관절점 기반 연결, 두 관절 IK, 발끝 접지·뒤꿈치 들기·발 접기·착지 보정과 몸통 연결부 마스크를 적용했습니다. 네 발의 순차 보행은 유지합니다.

`src/lib/walkingAnatomy.ts`가 몸통·머리·귀의 원래 비율과 어깨·엉덩이·무릎·발목·발바닥의 원화 좌표를 정의합니다. `animalMotion.ts`의 공통 발목 함수와 `PaintedAnimalArtwork.tsx`의 공통 부위 배치가 토끼와 같은 방식으로 움직입니다. 추가 이미지 생성이나 라이브러리 없이 기존 ImageGen 원화를 재사용합니다.

[여섯 자세 캡처와 검증 기록](docs/character-design/walkers-v6/README.md)을 보존합니다. 실제 브라우저에서 각각 12개 보행 자세의 네 발·몸통 픽셀 연결과 관절점 일치, 발끝 접지와 지면 속도, 320px 화면·일시정지·재개·새로고침을 검사합니다.

강아지·고양이의 각진 몸통은 둥근 등·엉덩이·가슴과 배가 살짝 들어간 곡선의 새 ImageGen 원화로 교체했습니다. 원화 비율과 기존 관절·발 접지 로직을 유지하며 메인 화면과 진행바에 함께 적용합니다. [몸통 원화·프롬프트·보행 캡처](docs/character-design/walkers-v7/README.md)에 제작 기록을 보존합니다. `npm run characters`는 새 몸통의 WebP와 자산 좌표도 재생성합니다.

## 병아리 날개 방향과 접지

`chickAnatomy.ts`에서 기존 원화의 날개 어깨·깃털 끝과 다리·발목·발가락 접지점을 정의합니다. 날개 깃털은 뒤를 향하고, 발 그림의 투명 여백 대신 실제 발가락이 지면에 닿습니다. 도착 후에는 몸 전체를 위로 띄우지 않고 머리와 날개로 축하합니다. [수정 전후 여섯 자세와 검증 기록](docs/character-design/chick-v7/README.md)을 참고하세요.

## 8비트 왕자

친구 선택에 **왕자**를 추가했습니다. 32×48 픽셀·16색의 오리지널 SVG 스프라이트로 준비·12프레임 걷기·점프·착지·손 흔들기를 표현합니다. 보행과 지면이 같은 시계를 사용하며 일시정지·새로고침에서 자세를 복원합니다. 모션 감소와 기존 도착 효과음·별 보상도 지원합니다. [시안과 제작 기록](docs/character-design/prince-pixel-v1/README.md)을 참고하세요.

정지·만세 자세는 두 다리를 곧게 펴고 부츠를 분리했으며, 걷기에서도 무릎이 과하게 접히지 않게 다리 비율을 맞췄습니다. [자세 수정 전후](docs/character-design/prince-upright-v3/README.md)를 보존합니다.

위쪽 진행바의 작은 왕자도 메인 캐릭터와 같은 보행 시계로 12프레임 걷기를 표시합니다. 일시정지·새로고침에서 같은 자세를 유지하고, 타이머가 0초가 되면 도착점에서 곧게 서 있습니다. 모션 감소 설정에서는 걷기 애니메이션을 생략합니다.

진행바의 친구 9종 모두 같은 시계를 사용합니다. 토끼·강아지·고양이·병아리와 공주는 정지 썸네일 대신 메인 화면의 원화 관절 리그를 표시하고, 동물의 다리·귀·꼬리와 공주의 팔다리가 동일한 자세로 움직입니다. 자동차·기차의 바퀴와 로켓의 불꽃도 메인 화면과 같은 픽셀 프레임을 재생합니다. 동물은 작은 배지에서 잘 보이도록 원화의 빈 위쪽 공간만 줄였습니다. 친구 선택 카드의 정지 썸네일은 유지합니다.

진행바의 위치는 실제 경과 시간을 반영하며, 일시정지·재개·새로고침에서는 현재 자세와 위치를 유지합니다. 시간이 끝나면 작은 친구는 도착점에서 정지하고, 메인 친구는 기존 결승선 통과·축하를 이어갑니다. 모션 감소 설정은 두 친구에 함께 적용됩니다. `tests/e2e/progress-characters.spec.ts`에서 9종 각각의 메인·진행바 관절/프레임 일치, 실제 렌더링 픽셀 변화, 일시정지·복원·재개·모션 감소와 도착 후 정지를 Chromium·모바일 WebKit에서 검사합니다.

## 시간 정렬과 부모 메뉴 재시작

남은 시간 숫자와 설명을 위아래로 배치해 각각 화면 중앙에 맞춥니다. 부모 메뉴의 처음부터 → 다시 출발은 기존 약속·캐릭터·처음 정한 시간을 유지하는 새 여행으로 재시작하고 화면 위쪽으로 돌아갑니다. 오디오 초기화의 동기 오류·비동기 거부가 타이머 제어를 중단하지 않으며, 닫힌 오디오 컨텍스트는 다음 소리 준비 동작에서 다시 만듭니다. `tests/e2e/parent-controls.spec.ts`에서 오디오 오류, 확인 취소, 일시정지·큰 화면의 터치 재시작, 새로고침 후 종료 시각 유지와 화면 크기별 숫자 중앙 정렬을 검사합니다.

시간 선택 버튼도 숫자와 ‘분’을 하나의 묶음으로 만들어 가로·세로 중앙에 배치합니다. 숫자와 단위 사이의 기준선 정렬은 묶음 안에서만 적용하며, 버튼 전체에 남아 있던 기준선 정렬 때문에 글자가 위쪽으로 붙던 문제를 교정했습니다. Chromium·모바일 WebKit에서 320px·390px·430px·가로·PC 화면의 실제 글자 영역 중심을 검사하고, 선택·직접 설정·단계 이동 후에도 정렬을 확인합니다.

## 활동 시작·활동 마무리와 별 달력

시간 선택 단계에서 두 가지 방식을 고릅니다. **활동 시작**은 ‘N분 뒤에 시작’하는 기다림이고, **활동 마무리**는 지금부터 ‘N분 동안 하기’입니다. 준비·진행·절반·마무리·도착 문구가 선택한 방식에 맞춰 바뀝니다. 선택한 방식은 저장되며, 진행 중 새로고침·일시정지·부모 메뉴 재시작에서도 유지됩니다. 예전 여행 데이터는 활동 시작으로 복원합니다. 캐릭터의 보행, 고정 결승선, 계절·낮밤 배경, 효과음과 화면 켜짐 유지는 그대로 사용합니다.

완료 화면에는 ‘도착’, ‘수고했어요’ 같은 마무리 안내 없이 **해야 할 행동을 한 번만** 표시합니다. 활동 시작은 ‘목욕하러 가요’, 활동 마무리는 ‘거품을 헹구고 몸을 닦아요’처럼 구체적인 행동으로 안내합니다. `activityMode.ts`의 `ACTIVITY_ACTIONS`가 활동별 행동 문구를 관리하며, 직접 입력은 ‘활동 시작해요 / 활동 여기까지 해요’로 표시합니다. 기존 완료 애니메이션·효과음·별 보상은 유지합니다.

시간이 끝나도 별은 자동 지급하지 않습니다. 약속한 활동을 실제로 시작하거나 마무리한 뒤 **약속 지켰어요**를 누르면 여행당 하나를 받습니다. 상단 별을 누르면 **별 달력**에서 날짜별 별과 약속·시간·활동 방식을 볼 수 있습니다. 별은 기기의 현지 날짜에 자동 기록되고 누적됩니다. 날짜가 바뀌어도 전체 별은 줄지 않습니다.

활동에 맞춘 안내 멘트 **100개**는 [`src/lib/activityMessages.ts`](src/lib/activityMessages.ts)에 있습니다. 씻기·잠자기·밥 먹기·정리하기·외출 준비·영상 끄기에 각각 시작 7개 / 마무리 7개(84개), 직접 입력한 활동에는 시작 8개 / 마무리 8개(16개)를 준비했습니다. 각 묶음은 시작·절반·마지막 구간·도착으로 나뉩니다. 잠자기 마무리는 편안한 쉼을, 영상 끄기는 화면을 끄고 쉬는 약속을 안내합니다. 직접 입력한 이름은 일반 활동 문구에 넣고, 알 수 없는 활동 ID도 일반 문구로 안전하게 표시합니다.

기존 30·60·90초의 표시 간격과 6·8초 노출, 마지막 10초·도착 안내를 유지합니다. 같은 구간의 정기 멘트는 순서대로 순환하며 여행마다 변형을 고릅니다. 여행 ID와 경과 시간으로 선택하므로 렌더링·일시정지·재개·새로고침·백그라운드 복귀 때 임의로 바뀌거나 밀린 멘트를 몰아서 보여주지 않습니다. 문구가 없을 때의 약속 아이콘과 반짝임, 모션 감소·큰 한국어 글자·안정적인 장면 배치를 유지합니다. `tests/activityMessages.test.ts`는 정확히 100개인 목록, 중복·주제·활동 방식·안정적인 선택·전체 변형 도달을 검사하고, `tests/e2e/activity-messages.spec.ts`는 모바일 화면의 표시·숨김·순환·복원·도착을 검사합니다.

**별 모으기**에서는 기본 20개부터 모을 수 있으며, 부모 메뉴 → **별 목표 · 달력 · 백업**에서 10·20·30·50·100개 또는 직접 1~1,000개로 정합니다. 목표를 바꿔도 별과 달력, 이미 완성한 별판은 보존합니다. 다 채운 뒤 **다음 별판 시작**을 누르면 완성한 별판을 보관하고, 초과분은 다음 별판으로 이어집니다. 큰 목표는 별 칸 100개씩 나눠 표시합니다. 벌점·별 차감·순위·연속 출석 조건은 없습니다.

같은 설정 화면에서 JSON 백업을 다운로드하거나 불러올 수 있습니다. 불러오기 전에 추가될 별 개수를 확인하고 **기록 합치기**를 누릅니다. 여행 ID로 중복을 제거해 같은 파일을 반복해서 가져와도 같은 별을 두 번 받지 않습니다. 현재 기록과 목표를 유지하며, 별이 없는 새 기기에서는 백업 목표도 가져옵니다. 백업 내용과 크기(최대 5MB)를 검사하고 잘못된 파일은 기존 기록을 바꾸지 않습니다.

저장 키는 `promise-journey:v1:timerMode`와 `promise-journey:v1:rewards`입니다. 기존 `todayStars`에 남아 있는 날짜·개수·중복 방지 ID는 처음 한 번 옮기고 원본 키도 보존합니다. 예전 저장 방식이 이미 버린 날짜의 별이나 약속·시간 정보는 복원할 수 없어 달력에 만들어 넣지 않습니다. 별은 브라우저 로컬에만 저장되므로 기기 변경·브라우저 데이터 삭제 전에 백업해야 합니다. 브라우저가 저장을 차단하면 해당 탭 메모리로 동작하므로 백업 파일을 보관하세요.
