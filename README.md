# 약속 여행

유치원생이 걷는 친구와 결승점까지 남은 거리로 시간을 이해하는 한국어 비주얼 타이머입니다.

**배포 주소: https://neegiman.github.io/timer/**

**저장소: https://github.com/neegiman/timer**

## 실행과 정적 빌드

Node.js 22와 npm을 사용합니다.

```sh
npm ci
npm run dev
```

개발 주소는 `http://localhost:3000/timer/`입니다. 앱은 `/timer`에 설치합니다.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview -- --port 17832
```

빌드는 `out/`를 생성합니다. `next.config.ts`는 `output: 'export'`, `basePath: '/timer'`, `trailingSlash: true`, `images.unoptimized: true`를 설정합니다. 빌드 후 Next.js 서버, API, 데이터베이스, 인증 서버가 필요하지 않습니다. `preview`는 로컬 검사에만 사용하는 파일 서버입니다.

`scripts/verify-export.mjs`가 생성된 HTML/CSS/JS의 경로와 `_next` 파일, 이미지, 11개 MP3를 확인합니다. 자산은 모두 `src/lib/assetPath.ts`의 `assetPath()`를 통해 `/timer` 접두어를 사용합니다.

```ts
assetPath('/sounds/finish.mp3'); // /timer/sounds/finish.mp3
assetPath('/images/meadow.svg'); // /timer/images/meadow.svg
assetPath('/characters/rabbit.webp'); // /timer/characters/rabbit.webp
```

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**는 **GitHub Actions**로 설정합니다. `main`에 푸시하거나 **Deploy Next.js to GitHub Pages** 워크플로를 직접 실행합니다.

`.github/workflows/deploy.yml`은 Node 22, `npm ci`, 타입 검사, 린트, 단위 검사, 정적 빌드, `out/` 확인, Pages 업로드와 배포를 실행합니다. `out/`, `.next/`, `node_modules/`는 커밋하지 않습니다. 도메인 루트 `https://neegiman.github.io/`로 배포 설정을 바꾸지 마세요.

```sh
npm run verify:live
```

게시된 `/timer/`의 HTML, Next.js 자산, 이미지, 11개 MP3 및 새로고침 응답을 확인합니다. 게시 완료 여부는 GitHub Actions의 배포 성공과 실제 URL의 응답으로 확인합니다.

## 사용 방법

1. 씻기·잠자기·밥 먹기·정리·외출 준비·영상 종료 또는 직접 약속을 고릅니다.
2. 5·10·15·20·30분 또는 1~120분을 정합니다.
3. 토끼·곰·강아지·고양이·병아리·자동차·기차·로켓을 고르고 **출발!**을 누릅니다.
4. 친구가 도착하면 약속한 일을 하고 **⭐ 약속 지켰어요**로 별 하나를 받습니다.

한 화면에 한 가지를 고르는 준비 흐름, 큰 아이콘, 기존의 전신 SVG와 부드러운 색상을 유지합니다. 숫자와 소리는 부모 메뉴에서 끌 수 있습니다. 일시정지·계속·처음부터·종료·전체화면도 부모 메뉴에 있습니다. 재시작과 종료에는 확인창이 있습니다.

별은 여행마다 한 번만 받습니다. 별을 빼거나 아이를 비교하지 않습니다. 오늘의 별 표시만 자정에 새로 시작하며, 완료된 여행에서 보상을 다시 받을 수는 없습니다.

## 고정 보행과 횡스크롤

메인 캐릭터는 장면 너비의 **42%**에 고정합니다. 위쪽의 작은 캐릭터만 실제 경과 시간에 비례해 집에서 깃발까지 이동합니다. 두 캐릭터는 서로 다른 역할을 가지며, 메인 캐릭터의 X좌표에 진행률을 적용하지 않습니다.

`Timestamp Timer → AnimationController → Shared Locomotion Clock → SVG Joints / Scenery / Destination` 구조입니다.

- `src/lib/animation.ts`: 메시지 단계와 `READY / WALK / SETTLE / JUMP / LAND / CELEBRATE` 상태를 계산합니다. 50%와 90%에서 걷기 주기를 재시작하거나 달리기로 바꾸지 않습니다.
- `src/lib/journey.ts`: 시작·종료의 800ms 부드러운 속도 전환, 보행 시계, 지면 거리, 반복 타일 오프셋, 마지막 10% 결승점 접근을 계산합니다. 프레임 수를 시간으로 사용하지 않습니다.
- `src/lib/characterPose.ts`: 발의 접지·지지·발끝 밀기·들어 올리기를 계산하고, 허벅지·무릎의 두 관절 IK와 발목 회전으로 목표 위치를 따라갑니다. 양발은 반 주기 차이로 교대하며 팔은 반대로 움직입니다. 0.55 SVG 단위의 작은 몸 바운스를 다리에서 보정합니다.
- `src/lib/motionProfiles.ts`: 친구별 보행 주기와 발바닥 기준 높이를 정의합니다. 자동차·기차는 바퀴 둘레에 맞춰 지면과 함께 회전합니다.
- `src/hooks/useJourneyRenderer.ts`: `requestAnimationFrame`에서 DOM의 `translate3d`, SVG 관절, Web Animation의 `currentTime`만 갱신합니다. React state는 매 프레임 갱신하지 않습니다. ResizeObserver로 크기를 캐시하고 소수점 캐릭터 폭을 사용해 지면과 발 속도를 맞춥니다.
- `src/components/timer/ScrollingScenery.tsx`: 기존 초원 색상과 구름·언덕·나무·꽃을 재사용한 네 개의 반복 SVG 레이어입니다. 480px 타일의 양 끝이 이어지며, 구름 0.08 / 언덕 0.20 / 나무 0.65 / 지면 1.00의 상대 속도로 움직입니다. 화면 전체를 흔들지 않습니다.
- `JourneyProgress.tsx`: 출발·도착 아이콘, 지나온 길, 실제 시간에 맞춰 이동하는 작은 친구입니다.
- `JourneyMessage.tsx`: 단계별 문구를 한 번씩 부드럽게 교체합니다. 긴 문구의 공간을 미리 확보해 전환 시 장면 높이가 갑자기 바뀌지 않습니다.
- `JourneyPath.tsx`: 고정된 전신 친구, 반복 배경과 **별도 단일 결승점 레이어**를 배치합니다. 깃발은 90%부터 나타나며, 남은 진행률과 함께 가까워져 정확히 100%에 캐릭터 앞에 도착합니다.
- `VisualTimer.tsx`, `src/app/globals.css`: 큰 상단 문구, 보조 숫자 시간, 진행 경로, 장면과 약속을 배치합니다. 320px부터 세로·가로·전체화면을 지원하며, 기존 디자인 토큰과 부모 메뉴를 유지합니다.

발이 지면을 지지하는 동안 발의 뒤쪽 이동 속도와 지면 스크롤 속도가 같습니다. 시작과 마지막 800ms에는 두 속도가 함께 부드럽게 변합니다. 50%·90%와 마지막 10초·3초에도 보행 속도가 갑자기 높아지지 않습니다.

| 경과 진행률 | 안내 |
| --- | --- |
| 0~49% | 즐겁게 걸어가 볼까? 🌈 |
| 50~89% | 벌써 반이나 왔어! 반만 더 가면 돼! 🌟 |
| 90~99% | 거의 다 왔어! 이제 곧 약속 시간이야! 🏁 |
| 100% | 도착! 약속 시간이 됐어! 참 잘했어! 🎉 |

50%에서는 별이 살짝 반짝이며 캐릭터는 계속 걷습니다. 시간이 0이 되면 지면과 배경을 멈추고 `SETTLE(350ms) → JUMP(600ms) → LAND(400ms) → CELEBRATE(1600ms)`를 순서대로 실행합니다. 도착 화면을 유지하고 2.95초 뒤 별 보상 버튼을 보여줍니다. 완료 효과음은 CELEBRATE에서 한 번 재생합니다.

종료 순서는 저장된 도착 시각으로 복원합니다. 중첩 timeout이나 비동기 delay 체인을 사용하지 않습니다. 새로고침·백그라운드 복귀 시 시각으로 보정하고, 종료·재시작은 이전 프레임과 오디오를 취소합니다.

일시정지하면 타이머, 관절, 몸동작, 배경, 결승점과 작은 진행 캐릭터를 모두 유지합니다. 재개 시 새 종료 시각과 UI 시계를 같은 순간에 갱신해 메시지 임계값을 잠깐 거슬러 올라가지 않습니다. 일시정지 후 새로고침도 같은 자세와 스크롤을 복원합니다.

`prefers-reduced-motion`에서는 반복 관절·바운스·배경 스크롤·큰 축하 동작을 제거하고 별 두 개만 표시합니다. 작은 진행 캐릭터, 결승점 접근과 실제 타이머 시각은 유지합니다.

## 저장과 모바일 소리

`localStorage` 키는 `promise-journey:v1:` 접두어를 사용합니다. 캐릭터, 시간, 약속, 소리, 숫자 표시, 오늘의 별, 진행 중인 여행, 재생한 소리의 기록을 저장합니다. 잘못된 데이터는 기본값으로 대체하며 저장소가 제한되면 현재 탭의 메모리로 동작합니다.

실제 종료 시각을 저장합니다. `visibilitychange`와 `pageshow`에서 현재 시각을 확인하므로 탭 전환·화면 잠금·Safari 정지 때문에 시간이 연장되지 않습니다. 만료 후 돌아오면 도착 연출을 시작합니다.

**출발!** 버튼의 명시적 입력에서 Web Audio 컨텍스트를 활성화하고 MP3를 디코딩합니다. 시작·절반·결승점 인지·도착에는 부드러운 차임을 한 번씩 사용하며 걷는 동안 소리를 반복하지 않습니다. `finish.mp3`와 별 버튼의 `success.mp3`는 서로 다른 효과음입니다. 세션별 재생 기록으로 새로고침 후 완료음을 다시 울리지 않습니다.

`public/sounds/`의 11개 MP3는 직접 합성한 자산이며 `npm run sounds`로 다시 만들 수 있습니다. 현재 흐름에서는 시작·절반·결승점 인지·도착·별 보상 효과음을 사용합니다. 원격 폰트나 이미지에 의존하지 않습니다.

실제 iPhone은 잠금·무음·브라우저 정책에 따라 백그라운드 소리를 막을 수 있습니다. 종료 시각은 유지하며 복귀 후 재생에 다시 탭이 필요하면 **소리 켜기**를 표시합니다. 실행 중 새로고침으로 오디오 컨텍스트가 사라지는 경우도 같은 안내를 제공합니다.

기본 친구는 `type: 'illustration'` 전신 SVG입니다. `type: 'image'`, `src: '/characters/파일명.webp'`를 사용하면 `/timer` 접두어가 적용됩니다. 이모지 대체 표시도 지원합니다. ImageGen 토끼 원화와 자세 참고표는 [캐릭터 디자인 기록](docs/character-design/README.md)에 있습니다. 이번 작업은 기존 SVG 관절과 초원 자산을 재사용하며 새 라이브러리를 추가하지 않았습니다.

## 전체화면

**부모 메뉴 → 전체화면**으로 진입하고 **전체화면 끝내기**로 돌아옵니다. 브라우저 Esc나 자체 종료에도 메뉴 상태가 갱신됩니다. 전체 페이지를 대상으로 하므로 부모 메뉴와 확인창도 사용할 수 있습니다.

지원하지 않거나 요청이 거절된 브라우저는 페이지 안에서 확장하는 **큰 화면 보기**를 사용합니다. 이 모드는 주소창을 숨기지 않습니다. Esc는 열린 부모 메뉴부터 닫고, 메뉴가 없으면 큰 화면을 끝냅니다. 새로고침은 기본 화면으로 돌아갑니다. 전환·회전 시 타이머 시각과 별은 유지됩니다.

가로 전체화면은 왼쪽에 장면, 오른쪽에 안내·진행 경로·약속을 배치합니다. 소리 재활성화 안내가 나타나면 장면 높이도 함께 줄여 발과 캐릭터가 잘리지 않도록 합니다.

## 검증

```sh
npx playwright install chromium webkit
npm run build
npm run test:e2e
```

실제 `out/`만 `/timer/`에서 제공하는 테스트 서버를 사용합니다. 단위 검사 18개와 Chromium 및 iPhone 크기 WebKit의 브라우저 시나리오 40개로 다음을 확인합니다.

- 실제 시각의 0/25/50/75/100%, 일시정지·재개·새로고침·백그라운드 복원, 직접 입력, 확인창과 별 중복 방지.
- 메인 X좌표 고정, 양발 교대, 팔 반대 움직임, 실제 SVG 발바닥의 지면 접촉 및 발과 지면의 같은 이동 속도.
- 반복 SVG 타일 경계의 픽셀 비교, 느린 원근 레이어, 50%·90% 메시지 한 번 전환, 재개 시 임계값 깜빡임 방지.
- 90% 전 결승점 없음, 단일 결승점의 연속 접근, 1/10/120분 모두 정확히 0초에 도착, 스크롤 정지와 순차 축하.
- 전신 친구 8종, 모션 감소, 320px·휴대폰·태블릿·데스크톱·가로 화면, 네이티브/대체 전체화면, 새로고침과 `/timer` 자산 경로.
- 시작·도착 효과음의 실제 디코딩 및 한 번 재생, 완료 새로고침 후 보상 저장.

Windows WebKit에는 `AudioContext`가 없어 실제 디코딩·출력 횟수 검사는 Chromium에서 실행합니다. WebKit은 모바일 화면·보행·메시지·제어·복원을 검사합니다. 네이티브 전체화면을 지원하지 않는 모바일 WebKit에서는 해당 검사 하나를 건너뛰고 큰 화면 보기 검사를 실행합니다.

실제 iPhone 하드웨어의 스피커·잠금·복귀 소리는 별도 확인이 필요합니다. Safari에서 씻기 → 10분 → 토끼 → 출발!을 누른 뒤 소리, 일시정지·계속, 잠금·복귀, 도착 소리 한 번, 별 저장과 게시 URL 새로고침을 확인하세요.
