# 로켓의 8비트 우주

로켓을 선택하면 전용 우주를 표시합니다. 계절·낮·밤 선택은 다른 캐릭터를 위해 저장되며 우주의 모습에는 영향을 주지 않습니다.

- 배경 원화: 내장 ImageGen으로 생성한 [source.png](source.png).
- 최종 프롬프트: [prompt.txt](prompt.txt).
- 실제 사이트 시안: [runtime-preview.png](runtime-preview.png), 낮·밤 및 모바일·가로 화면 비교.
- 런타임 자산: `public/images/space-v1/nebula.webp`, `stars.svg`, `near-stars.svg`.
- 재생성: `npm run space`. 성운 원본을 픽셀 격자로 정규화한 뒤 좌우 반전 타일을 연결합니다. 반복 경계의 양쪽 픽셀 열이 일치합니다.

성운·먼 별·가까운 별은 각각 이동 거리의 0.04 / 0.22 / 0.60배로 움직입니다. 고리가 있는 행성·푸른 행성·작은 위성은 기존 픽셀 로켓에 맞춘 SVG이며 별도 레이어에서 천천히 떠 있습니다. 나무·풀·사계절 원화는 로켓 화면에 렌더링하지 않습니다.

UFO는 48초 주기의 10~18초에 부드럽게 나타나 가로질러 사라집니다. 30초에는 꼬리가 없는 작은 픽셀 별빛이 0.8초 반짝입니다. 모든 이동과 불빛은 실제 타이머의 경과 시간으로 계산하여 일시정지·재개·새로고침 시 위치를 유지합니다. 동작 줄이기 설정에서는 이동과 이벤트를 줄입니다. 도착점은 스크롤 레이어 밖의 고정 위치를 유지합니다.

검증에는 반복 경계 픽셀 검사, 낮·밤·계절 변경 전후 화면의 완전 일치, UFO 등장·퇴장·일시정지·새로고침, 모바일 레이아웃, 도착·완료음·별 보상 테스트가 포함됩니다.
