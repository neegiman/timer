# 자동차 도로와 기차 레일

자동차에는 회청색 도로·크림색 가장자리·노란 중앙 점선을, 기차에는 두 줄의 철제 레일·나무 침목·자갈 바닥을 표시합니다. 기존 사계절 원화 풍경 위에 해당 차량의 지면만 겹칩니다. 낮에는 따뜻하고 부드러운 색, 밤에는 차분한 푸른 색을 사용합니다.

정적 SVG 4개를 `scripts/generate-vehicle-ground.mjs`에서 제작합니다. `npm run vehicle-ground`로 재생성할 수 있으며 외부 이미지·라이브러리가 필요하지 않습니다. 실제 파일은 `public/images/vehicle-ground-v1/`에 있고 `/timer/images/vehicle-ground-v1/…`로 로딩합니다. [낮·밤 적용 화면](runtime-preview.png)을 보관합니다.

모든 타일은 기존 지면과 같은 480px 반복 폭, 1배 이동률을 사용합니다. 별도 CSS 애니메이션 대신 `useJourneyRenderer`의 시간·이동 거리를 함께 사용하여 바퀴 회전, 일시정지, 재개, 드래그 시간 조절, 새로고침, 완료 정지를 유지합니다. 기찻길은 높이를 96px로 고정하고 위에서 24px 지점을 바퀴 접점에 맞추므로 세로·가로 화면에서도 레일 위에 정확하게 섭니다. 도착선은 기존의 고정 레이어를 사용합니다.

수정 파일: `ScrollingScenery.tsx`에서 캐릭터별 지면을 추가하고, `JourneyPath.tsx`에서 캐릭터 ID를 전달하며, `globals.css`에서 바닥 접점과 낮·밤 전환을 배치합니다. 로켓의 우주와 동물·사람의 기존 길은 유지합니다.

검증: 타일의 양끝 픽셀 일치, 레일 연속성, 바퀴·레일 접점, 지면 스크롤 동기화, 낮·밤 전환 시 타이머 유지, 일시정지·재개·새로고침·완료, 320px/390px/가로 화면, 모션 감소와 정적 배포 자산 로딩을 확인합니다.
