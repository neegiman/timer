# 토끼 원화 비율과 관절 연결 교정

이 문서는 이전 교정 기록입니다. 이후 [선택 이미지와 발목 보행 수정](../rabbit-motion-v3/README.md)에서 가까운 다리는 몸통 앞에 두고 부착 부위를 부드럽게 겹치도록 개선했습니다.

기존 원화 아틀라스를 그대로 사용하고, 토끼의 배치와 보행 뼈대를 교정했습니다. SVG 시안의 관절을 원화에 그대로 적용하면서 몸통이 납작해지고, 반대편 앞다리의 뿌리가 어깨 밖에 위치하며, 가까운 다리가 몸통 위로 드러나는 문제가 있었습니다.

## 변경

- `src/lib/rabbitAnatomy.ts`: 토끼 몸통·머리·귀의 원화 비율, 회전 중심, 네 다리의 부착 위치를 같은 좌표계로 정의합니다.
- `src/lib/animalMotion.ts`: 토끼 앞다리를 가슴 안쪽, 뒷다리를 엉덩이 안쪽으로 옮기고 뼈 길이를 조절합니다. 실제 타이머와 보행 비교 화면이 같은 값을 사용합니다.
- `src/components/PaintedAnimalArtwork.tsx`: 몸통·머리·귀·다리·발의 비율을 보존하고, 토끼 다리의 뿌리가 몸통 뒤에 가려지도록 순서를 변경합니다. 다리 관절과 발의 연결 부위는 겹치며 발바닥 기준 높이는 유지합니다.
- 다른 동물의 비율과 관절 위치는 유지합니다. 타이머 시간 계산, 사운드, 별 저장은 기존 기능을 사용합니다.

## 검사

`tests/paintedAnimals.test.ts`는 원화 비율과 네 다리 뿌리 주변의 불투명한 몸통 겹침을 검사합니다. 기존처럼 반대편 앞다리가 가슴 밖에 붙으면 실패합니다.

`tests/e2e/rabbit-artwork.spec.ts`는 실제 렌더링된 원화를 보행 한 주기의 12개 자세에서 픽셀로 검사합니다. 몸통에서 이어지는 불투명 픽셀 영역에 앞·뒷발 네 개가 모두 연결되어야 하며, 다리 뿌리는 몸통 뒤에 있어야 합니다. Chromium과 모바일 WebKit에서 실행합니다.

기존 검사로 발 접지와 지면 이동 속도, 네 발 가시성, 일시정지·재개·새로고침·모션 감소·도착 자세·모바일 가로/세로 배치를 확인합니다.
