# 공주 관절의 중심선·굵기·겹침 보정

이전 버전은 관절 좌표를 맞췄지만 부위별 그림을 길이에 맞춰 축소하는 과정에서 실제 연결부의 굵기와 중심선이 달라졌습니다. v4는 기존 원화를 그대로 사용하고 SVG 조립·겹침을 수정합니다. 원본 PNG·WebP 픽셀을 편집하거나 새 그림을 생성하지 않았습니다.

## 연결부 기준

실제 원화의 알파가 160 이상인 단면을 관절 축에 수직으로 측정했습니다. 팔꿈치·무릎·발목에서 연결되는 두 그림의 굵기 차이는 6% 미만, 회전축과 단면 중심의 차이는 디자인 좌표 0.2 미만으로 검사합니다. 런타임에는 이미지 픽셀을 읽지 않습니다.

- 어깨의 원화 회전축을 소매 위의 잘린 피부 단면에서 소매 안쪽 중심으로 옮겼습니다. 소매가 몸통과 충분히 겹친 상태로 회전합니다. 위 팔의 실제 길이는 21, 아래 팔은 18입니다.
- 팔꿈치 원화의 끝·시작 중심선을 맞추고, 아래 팔의 가로 폭을 1.12배로 맞췄습니다. 길이와 굵기는 별도의 기준으로 관리합니다.
- 무릎 중심선을 맞추고 종아리 가로 폭은 5/6로 맞췄습니다. 발목은 원화의 실제 가는 부위에 연결하며, 신발의 피부 단면 중심도 맞췄습니다.
- 종아리가 발목 아래로 길게 튀어나오지 않도록 원화 표시 영역을 제한합니다. 신발은 종아리 뒤에 그려져 열린 발목 단면이 정강이 위에 떠 보이지 않습니다.
- 아래 부위를 먼저 그리고 위 부위가 연결부를 덮습니다. SVG 알파 마스크로 부위 끝을 겹쳐 팔꿈치·무릎의 둥근 절단선을 부드럽게 연결합니다. 관절 행렬과 발 접촉은 기존 IK를 유지합니다.

## 몸통과 허리

치마 전체를 좌우로 회전시키던 동작은 허리 연결부를 벌어지게 하므로 제거했습니다. 치마와 몸통은 같은 고정 허리를 사용합니다. 몸통 원화의 아래 리본·옷자락을 SVG 표시 영역에서 가리고 치마의 리본 하나가 보이도록 위치와 폭을 맞췄습니다.

머리·긴 머리카락·왕관 스타일, 타이머의 실제 시간 계산, 발 접촉, 배경 속도, 음향, 별 보상, 전체화면, 정적 배포 설정은 유지합니다.
