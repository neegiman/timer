# 토끼 선택 이미지와 발목 보행 수정

선택한 토끼가 사라진다는 제보와, 보행 중 관절이 맞지 않는 모습을 수정한 기록입니다. 기존 ImageGen 원화와 타이머 구조를 재사용했습니다. 새 이미지나 애니메이션 라이브러리는 추가하지 않았습니다.

## 선택 이미지

선택 화면은 중첩 SVG 대신 원화 아틀라스의 완성된 토끼 영역을 CSS 배경으로 표시합니다. 선택된 항목에만 적용하던 변형 애니메이션도 제거했습니다. 같은 방식은 곰·강아지·고양이·병아리의 선택 그림에 적용합니다. 메인 화면의 관절 애니메이션은 유지합니다.

기존 사라짐 현상은 Windows의 Chromium과 모바일 크기 WebKit에서는 재현되지 않았습니다. 특정 브라우저의 원인으로 확정하지 않고, 선택 시 불필요한 변형과 중첩 SVG를 없애 표시를 안정화했습니다. 반복 선택, 단계 이동, 새로고침 이후 실제 그림 픽셀이 남아 있는지 검사합니다.

## 관절과 접지

- 가까운 다리는 몸통 앞에서 움직이고, 부착 부위만 부드럽게 겹칩니다. 먼 다리는 몸통 뒤에 둡니다. 이전처럼 모든 다리를 몸통 뒤에 숨기지 않습니다.
- 발목을 항상 수평으로 고정하지 않고 **접지 → 뒤꿈치 들기 → 발 접기 → 착지 준비**로 연결합니다.
- 발끝을 중심으로 회전할 때 무릎·엉덩이 위치를 역기구학으로 보정해, 지지하는 발끝이 지면 위에 남도록 합니다. 발끝과 배경은 같은 보행 시계를 사용합니다.
- 몸의 짧고 큰 상하 움직임을 작고 완만한 움직임으로 줄였습니다. 반복 경계와 발을 떼는 순간의 각도는 연속적으로 이어집니다.
- 토끼의 기존 몸통·머리·귀 비율과 관절 뿌리 위치는 유지합니다. 다른 동물의 보행과 타이머 시간 계산은 유지합니다.

`animalMotion.test.ts`는 발끝 회전까지 포함한 관절 위치·접지, 각도 연속성, 무릎 방향을 검사합니다. `rabbit-artwork.spec.ts`는 선택 그림의 실제 픽셀, 발끝을 딛고 뒤꿈치를 드는 동작과 지면 속도, 12개 자세의 몸통–발 픽셀 연결을 검사합니다. 기존 브라우저 검사는 일시정지·새로고침·재개·모션 감소·배경·도착·8종 선택을 확인합니다.

실제 iPhone 하드웨어의 표시와 소리는 별도 확인 대상입니다. 모바일 WebKit 테스트는 실기기 Safari 검증을 대체하지 않습니다.

2026-10-09 검증: TypeScript·lint·정적 빌드·`/timer` 자산 검사, 단위 검사 34개, 관련 Chromium·모바일 WebKit 브라우저 검사 32개 통과. 모바일 크기로 추가 확인한 발목·접지 검사 2개도 통과했습니다.
