# 토끼 뒷다리 회전축과 원화 관절 정렬

이전 수정은 다리의 픽셀 연결과 발목 접지를 개선했지만, 뒷다리의 회전 중심이 여전히 낮고 앞쪽에 있었습니다. 원화의 둥근 허벅지와 회전하는 다리의 관절이 일치하지 않았습니다.

## 변경

160×210 캐릭터 좌표계에서 가까운 엉덩이 축을 `(48, 164) → (40, 157)`, 먼 축을 `(55, 162) → (47, 155)`로 옮겼습니다. 허벅지 뼈 길이는 `24 → 34`, 정강이는 `25 → 29`로 조정해 무릎이 허벅지 앞쪽에서 접히도록 했습니다.

그림의 사각형 위쪽 중심을 회전축으로 사용하지 않습니다. 원화 부위 안의 엉덩이·무릎·발목 점을 지정하고, 각 이미지의 크기·이동·방향을 뼈에 맞춥니다. 원화의 비율은 유지합니다.

| 부위 | 시작 관절의 원화 좌표 | 다음 관절의 원화 좌표 |
| --- | --- | --- |
| 허벅지 | 엉덩이 `(91, 48)` | 무릎 `(106, 239)` |
| 정강이 | 무릎 `(64, 29)` | 발목 `(69, 245)` |
| 뒷발 | 발목 `(51, 55)` | 발끝 접지 `(216, 127)` |

좌표는 각각의 아틀라스 부위 왼쪽 위를 기준으로 합니다. 발목 위치 변경에 따라 발바닥 높이도 원화 좌표에서 계산합니다. 발끝 접지 보정, 지면 속도, 일시정지·재개와 시간 계산은 같은 시계를 유지합니다. 보행 구조 SVG도 같은 접지 위치에 맞췄습니다. 기존 ImageGen 이미지 파일은 변경하지 않았습니다.

## 검증

`paintedAnimals.test.ts`는 각 관절점과 발끝 주변이 실제 불투명한 원화 안에 있는지 검사합니다. `rabbit-artwork.spec.ts`는 한 주기의 12개 자세에서 **원화의 관절점과 실제 회전축 사이 오차가 0.01 캐릭터 좌표 미만**인지 검사합니다. 몸통과 네 발의 픽셀 연결, 발끝 접지와 지면 속도, 선택 그림도 함께 확인합니다.

이전에는 관절의 픽셀 연결만 검사해, 연결된 상태에서도 회전 중심이 어긋나는 문제를 잡지 못했습니다. 관절 정렬 검사와 실제 관절점 캡처를 추가했습니다. 실제 동물의 실측 모션 캡처는 아닙니다.
