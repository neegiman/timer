# 토끼 귀와 머리의 연결 교정

귀 부위의 사각형 아래쪽을 기준으로 배치하면서 실제 털이 있는 귀 뿌리와 회전축이 어긋났습니다. 가까운 귀는 머리의 투명한 가장자리에 걸쳐 있어 움직일 때 틈이 보였습니다.

`rabbitAnatomy.ts`에서 귀의 실제 뿌리 좌표를 기준으로 배치를 계산합니다. 가까운 귀는 머리 좌표 `(111, 131)`, 먼 귀는 `(120, 129)`에 고정합니다. 귀의 원화 비율과 움직임 크기는 유지합니다.

`PaintedAnimalArtwork.tsx`는 토끼의 두 귀를 머리 뒤에 그립니다. 머리 털이 귀 뿌리의 끝부분을 덮어 자연스럽게 이어지며, 고개를 움직일 때 귀도 같은 머리 좌표계를 따릅니다. 다른 동물의 그리기 순서는 유지합니다. 기존 ImageGen 원본과 WebP는 변경하지 않았습니다.

## 검사

`paintedAnimals.test.ts`는 귀 뿌리가 원화의 불투명한 털 안에 있고, 머리의 불투명한 영역 안쪽에 부착되는지 검사합니다.

`rabbit-ears.spec.ts`는 실제 타이머의 걷기 8자세, 모션 감소, 점프·착지·축하의 총 12자세를 검사합니다. 머리와 귀를 각각 따로 렌더링해 두 이미지가 겹치는 불투명 픽셀을 세고, 연결 부위가 머리 털에 가려지는지도 확인합니다. 귀 둘이 서로 닿는 것으로 머리 연결 검사를 통과할 수 없도록 각 귀를 따로 검사합니다.

실제 iPhone 하드웨어 확인은 포함하지 않습니다. Chromium과 모바일 크기 WebKit을 사용합니다.
