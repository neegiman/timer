# 공주 팔·다리와 몸통 연결 보정

현재 관절 중심선·굵기·겹침은 [v4 보정](../princess-rig-v4/README.md)을 참고하세요. 이 문서는 v3 구현 기록입니다.

기존 [긴 머리 원화](../princess-v2/README.md)를 재사용하고, 원화 조립 좌표·회전축·가림 순서를 수정했습니다. 새 이미지 생성이나 원본 픽셀 편집은 없습니다.

## 수정 내용

- 이 3/4 방향 그림에서 가까운 쪽은 화면 왼쪽입니다. 가까운 어깨와 골반, 먼 어깨와 골반을 각각 같은 쪽에 배치했습니다. 팔의 원화도 해당 방향에 맞게 연결합니다.
- 어깨 회전축은 `(66, 83)`, `(94, 83)`입니다. 먼 팔은 몸통 뒤, 가까운 팔은 몸통·치마 앞에 그려져 팔이 몸통을 뚫거나 반대편에서 나오는 모습을 줄였습니다.
- 두 골반 회전축을 치마 안의 `(73, 121)`, `(85, 121)`로 올렸습니다. 이전 `(76, 147)`, `(84, 147)`는 치마 아래쪽에서 다리가 시작해 무릎과 몸통의 비율이 어긋났습니다.
- 허벅지·종아리를 `40`, `35`로 맞춰 허벅지는 치마에 가려지고 무릎은 치마 끝 안쪽에서 움직입니다. 발은 기존 지면 `205`를 유지하며 접지와 배경 속도는 같은 타임스탬프 시계를 따릅니다.
- 점프와 손 흔들기는 양쪽 어깨 바깥으로 팔을 올립니다. 가까운 팔이 얼굴 뒤로 가려지는 방향을 수정했습니다.

## 시각 확인

[정지·보행 8자세·점프·축하·원화 비교 캡처](./standing-walking-celebration.png)는 실제 React SVG 컴포넌트와 보행 계산을 Chromium에서 렌더링한 화면입니다. 오른쪽 아래 원화는 비율 참고용 선택 이미지입니다.

## 검증

- 단위 검사: 400개 보행 자세에서 몸통과 어깨·골반의 좌우 일치, 골반 위치, 무릎 가림, 발 접촉, 보행 연속성, 축하 시 얼굴 바깥 팔 위치를 확인합니다.
- Chromium·모바일 WebKit: 320px 화면에서 선택, 걷기, 일시정지·재개, 새로고침, 모션 감소, 도착, 별 보상을 확인합니다.
- 브라우저 캔버스로 실제 원화의 알파 실루엣을 읽어 팔·다리가 몸통에서 분리된 별도 덩어리로 보이지 않는지 검사합니다. 투명 여백과 작은 원화 얼룩은 판정에서 제외합니다.
- 같은 검사에서 실제 신발 픽셀의 바닥을 확인합니다. 관절 좌표가 일치하더라도 그림이 땅에서 뜨면 실패합니다.

타이머, 소리, 보상, 전체화면, 낮·밤 배경, `/timer/` 정적 배포 설정은 기존 기능을 유지합니다.
