# 긴 머리와 자연스러운 팔 보행

기존 공주의 얼굴·왕관·분홍 드레스 스타일을 유지하면서 허리까지 내려오는 긴 밤색 머리와 어깨부터 움직이는 팔로 수정했습니다.

팔·다리의 현재 배치와 회전축은 [몸통 연결 보정 v3](../princess-rig-v3/README.md)에 정리했습니다. 아래 수치는 v2 최초 구현 기록입니다.

## 원화

- **내장 ImageGen**으로 기존 원화를 참조하여 수정했습니다. 투명 배경을 유지했고 CLI/API fallback을 사용하지 않았습니다.
- 최종 생성 프롬프트: [prompt.txt](./prompt.txt)
- 수정 원본 PNG: [princess-upper-atlas.png](./princess-upper-atlas.png), 1448×1086
- 무손실 사이트용 파일: [princess-upper-v2.webp](../../../public/characters/raster-v1/princess-upper-v2.webp)
- 머리·긴 뒷머리·소매 없는 몸통·위 팔·아래 팔·긴 머리 전신 선택 이미지: [princessUpperAtlas.json](../../../src/lib/princessUpperAtlas.json)
- 실제 브라우저의 보행 캡처: [walking-poses.png](./walking-poses.png)

기존 [v1 원화](../princess-v1/princess-atlas.png)의 치마·다리·신발은 그대로 재사용합니다. `princessArtwork.ts`가 각 부위에 맞는 원화와 영역을 선택합니다. `scripts/prepare-princess-atlas.mjs`는 두 PNG를 무손실 WebP로 변환하며 픽셀을 그리거나 보정하지 않습니다. 사이트 자산은 `/timer/characters/raster-v1/`에서 로드합니다.

## 팔과 머리의 연결

기존에는 팔의 회전축이 소매 아래에 있어 위 팔이 짧았고, 팔꿈치가 고정돼 있었습니다. v2는 소매를 위 팔 원화에 포함하고, 어깨의 회전축을 몸통 그림 안에 연결합니다. 위 팔 길이는 25, 팔꿈치부터 손목까지는 18로 조정했습니다. 아래 팔의 겹치는 경계는 SVG 마스크로 부드럽게 연결하며 원본 그림은 유지합니다.

어깨 각도는 해당 다리의 발 위치를 사용하여 반대 방향으로 움직입니다. 팔꿈치는 앞으로 돌아올 때 조금 더 굽혀집니다. 두 팔은 같은 시간 시계를 따르며, 반복 경계가 이어집니다. 소매는 팔과 함께 움직이고, 뒤쪽 소매가 머리카락이나 몸통에 완전히 가려지지 않도록 그리는 순서를 조정했습니다.

긴 뒷머리는 몸통 뒤에 배치합니다. 머리와 같은 목 회전을 적용하고, 머리 그림 안에 있는 별도 뿌리를 중심으로 1.2도 이내로 흔들립니다. 머리·왕관과 긴 머리가 떨어지지 않도록 실제 원화 안에 있는 지점을 기준으로 연결합니다. 선택 화면도 긴 머리 전신 원화로 변경했습니다.

축하할 때는 500ms 동안 팔을 천천히 든 뒤 어깨는 거의 유지하고 팔꿈치로 손을 흔듭니다. 타이머·배경·발 접촉·일시정지·재개·새로고침·별 보상은 기존 기능을 유지합니다. 모션 감소 환경에서는 반복 동작을 멈춥니다.

## 검증

`princessMotion.test.ts`에서 두 원화의 무손실 변환, 관절이 실제 그림 안에 있는지, 머리카락 연결, 400개 보행 자세의 발 접촉·팔 역방향 움직임·팔꿈치 범위·보행 경계·축하 진입을 검사합니다. `princess-artwork.spec.ts`와 전체 캐릭터 브라우저 검사는 Chromium 및 모바일 WebKit에서 선택·걷기·일시정지·재개·새로고침·모션 감소·도착·별 보상·320px/가로 화면을 확인합니다.
