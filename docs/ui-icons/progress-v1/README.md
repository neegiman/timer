# 원화 진행바와 시간 조절

기존 토끼 원화와 같은 부드러운 그림책 질감으로 길·집·깃발을 제작했습니다. 베이지색 길 위로 지나온 구간을 초록색 붓 터치로 표시하고, 선택한 작은 캐릭터는 기존 관절 애니메이션을 그대로 사용합니다.

- 내장 ImageGen으로 생성한 투명 원본: [길](trail-source.png), [집](home-source.png), [깃발](flag-source.png).
- 실제 생성에 사용한 최종 프롬프트와 참조 이미지: [prompts.json](prompts.json).
- 사이트 적용 화면: [runtime-preview.png](runtime-preview.png).
- 런타임 자산: `public/images/progress-v1/trail.webp`, `public/images/story-v1/home.webp`, `flag.webp`.
- 변환: `npm run progress-art && npm run icons`. Sharp는 투명 여백 정리와 크기·WebP 변환에만 사용합니다.

진행 중 길이나 작은 캐릭터를 누르고 왼쪽으로 끌면 남은 시간이 늘고, 오른쪽으로 끌면 줄어듭니다. 범위는 처음 선택한 전체 시간부터 0초까지이며 1초 단위로 반영합니다. 드래그하는 동안 여행을 잠시 멈추고 남은 시간을 보여줍니다. 손을 놓으면 종료 시각을 다시 계산하여 이어갑니다. 일시정지 중에 조절했다면 계속 일시정지합니다. 출발점으로 되돌려도 여행 ID와 전체 시간은 유지하므로 별을 중복 지급하지 않습니다.

끝 지점을 미리 보는 동안은 도착 연출이나 효과음을 실행하지 않습니다. 끝에서 손을 놓으면 도착 순서를 시작합니다. 포인터 취소·Escape·탭 이탈은 원래 남은 시간으로 복구하며 조절하는 데 걸린 시간은 차감하지 않습니다. 완료된 여행의 진행바는 조절할 수 없습니다. 재시작은 기존 부모 메뉴의 확인 절차를 사용합니다.

키보드는 좌우 화살표로 5초, Page Up/Down으로 1분씩 조절합니다. Home은 전체 시간, End는 도착입니다. 화면 읽기 프로그램에 슬라이더 이름·진행률·남은 시간을 제공합니다. 숫자 표시를 꺼도 드래그 중 남은 시간을 확인할 수 있습니다.

`seekSession`은 실제 시각으로 종료 시각을 변경하고, 임시 미리보기는 localStorage에 매 프레임 저장하지 않습니다. 메인 캐릭터·진행 경로·배경·안내·고정 도착점은 같은 미리보기 시간을 사용합니다. 이동 입력은 requestAnimationFrame으로 묶고, 멈춘 장면은 입력이 바뀔 때 한 번만 다시 그립니다. 기존 `/timer` 자산 경로와 정적 배포를 유지합니다.

검증: 타임스탬프·클램핑·일시정지·종료 불변성 단위 테스트, Chromium/모바일 WebKit에서 앞뒤 드래그·터치 이벤트·취소·키보드·새로고침·완료음 1회·별 보상 1회·320px/세로/가로 화면 테스트. Windows WebKit의 Web Audio 미지원으로 디코딩된 효과음 재생 횟수는 Chromium에서 검사합니다.
