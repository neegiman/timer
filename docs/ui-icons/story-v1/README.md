# 초기 토끼 원화에 맞춘 그림 아이콘

`docs/character-design/rabbit-concept.png`를 그림체 참조로 사용했습니다. 크림색·살구색·세이지 색, 따뜻한 윤곽선과 부드러운 원화 음영을 약속 선택과 준비 단계에 적용했습니다.

- 내장 ImageGen으로 악수·목욕·침대·밥·장난감 정리함·장화·TV·시계 이미지를 각각 생성했습니다. [최종 프롬프트](prompts.json)에 8개 요청을 보존합니다. CLI/API 대체 경로를 사용하지 않았습니다.
- `sources/`는 투명 배경 WebP 원본 보관본입니다. 생성 파일은 기본 생성 위치에도 유지합니다.
- `public/images/story-v1/`는 앱에서 사용하는 320px 투명 WebP와 보조 SVG입니다. 토끼 단계 아이콘은 초기 원화 자체를 재사용합니다. 직접 입력·집·깃발·보상 별은 작은 크기에 맞는 프로젝트용 SVG입니다.
- `StoryIcon`과 `PromiseIcon`은 `/timer` 자산 경로를 일관되게 적용합니다. 그림은 장식으로 처리하고 옆의 큰 한글이 버튼 이름을 제공합니다. 저장된 사용자 약속도 ID로 그림을 찾으며 직접 입력·알 수 없는 ID는 연필 그림을 사용합니다.
- 악수 그림은 앱 상단, 48px 파비콘, 192px 앱 아이콘, 180px Apple 홈 화면 아이콘에 공유됩니다. 새 파일명을 사용해 이전 토끼 파비콘 캐시와 구분합니다.
- `npm run icons`는 보관본에서 앱 아이콘과 [그림체 모음](icon-family.png)을 다시 만듭니다. PNG 생성 원본을 처음 가져올 때만 `node scripts/prepare-story-icons.mjs <입력 manifest.json>`을 사용합니다.

캐릭터 보행·타이머·음향·보상 및 고정된 도착점의 위치 계산은 기존 구현을 사용합니다.

검증: 타입 검사·린트·정적 빌드와 `/timer` 자산 검사 통과. Chromium·모바일 WebKit의 기존 여행/애니메이션 검사 22개 통과, 별 그림 적용 후 도착·음향·보상·새로고침 시나리오 2개 재검사 통과. 320px·390px·PC 화면에서 새 그림 로드·파비콘 경로·단계 이동·가로 넘침을 확인했습니다. [320px 실제 화면](promise-selection-320.png)을 보존합니다.
